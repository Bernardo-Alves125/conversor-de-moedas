# 💱 Conversor de Moedas

Aplicativo de conversão de moedas criado com **React Native + Expo**.

Inspirado em tutoriais de React Native, mas com design e estrutura próprios.

## Funcionalidades

- Conversão em tempo real entre várias moedas
- Suporte a Bitcoin
- Interface moderna e dark mode
- Botão para inverter as moedas
- Cotações atualizadas via APIs gratuitas (Frankfurter.app e CoinGecko)

## Como rodar

1. Instale as dependências:
```bash
npm install
```

2. Inicie o projeto:
```bash
npx expo start
```

3. Escaneie o QR Code com o app **Expo Go** no seu celular (Android ou iOS).

## Tecnologias

- React Native
- Expo
- @react-native-picker/picker
- API Frankfurter (moedas fiduciárias)
- API CoinGecko (Bitcoin)

## Moedas suportadas

BRL, USD, EUR, GBP, JPY, CAD, AUD, CHF, CNY, ARS, MXN e BTC.
